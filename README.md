# BuildMeasure Pro — القياس الهندسي الشامل

تطبيق هندسي متكامل ومحلي (Offline-First) لمواقع البناء والمقاولات، لقياس الأطوال والمساحات والأحجام، ومسح الغرف وتجسيمها ثنائياً وثلاثياً، وحصر الكميات والمواد وتكاليفها، وتصدير التقارير الهندسية.

---

## 🛠️ المميزات الرئيسية (Core Features)

1. **قياس المسافات والأطوال بالكاميرا (Camera Measure):**
   - قياس مباشر بنقاط ليزرية متقاطعة وتتبع زوايا الميل (Pitch / Roll / Yaw).
   - نظام معايرة مرجعية (بطاقة بنكية 85.6 مم، ورقة A4، بلاطة 60 سم، أو الارتفاع المثلثي للهاتف).
   - مؤشر ذكي لاستقرار الهاتف وتنبيه عند الاهتزاز أو الحركة السريعة.

2. **مسح وتجسيم الغرف 2D / 3D (Room Scanner & Blueprint):**
   - رسم مخطط هندسي ثنائي الأبعاد للغرفة مع أطوال الجدران والمساحة والمحيط.
   - نموذج ثلاثي الأبعاد تفاعلي (Three.js) مع تدوير وتكبير وإضاءة معمارية.
   - إضافة فتحات الأبواب والنوافذ وخصم مساحاتها تلقائياً (Gross vs Net Area).
   - **تصدير المخطط إلى AutoCAD DXF**.
   - **تصدير المجسم ثلاثي الأبعاد إلى Wavefront OBJ**.

3. **قياس الأسطح والأسقف المائلة (Surface & Slope Measure):**
   - حساب المسقط الأفقي وزاوية الميل الحقيقية بالمستشعر وحساب المساحة الفعلية المائلة:
     $$A_{\text{true}} = \frac{A_{\text{projected}}}{\cos(\theta)}$$
   - خصم المناور والفتحات.

4. **مسح الأجسام ثلاثية الأبعاد وحساب الأحجام (3D Object & Volume):**
   - حساب أبعاد الصناديق والخزانات ومجسمات الموقع.
   - معامل الامتلاء (Solidity Factor) لفصل الحجم الإجمالي عن حجم المادة الصلبة الفعلي.
   - عرض 3D تفاعلي وتصدير بصيغة OBJ.

5. **حاسبة حصر الكميات والمواد (BOQ & Materials Takeoff):**
   - خرسانة مسلحة (قواعد، ميدات، أعمدة، بلاطات) مع تقدير أكياس الأسمنت والرمل والحصى والحديد.
   - تشطيبات (بلاط وبورسلان مع نسب الهدر، دهانات داخلية وخارجية، لياسة، عزل).
   - حفر وتربة مع معامل انتفاخ التربة وعدد نقلات القلابات.
   - استيراد فوري للقياسات من المشروع النشط دون إعادة كتابة.

6. **المكتبة الهندسية ومحول الوحدات:**
   - تحويل فائق الدقة لوحدات الطول والمساحة والحجم.
   - حاسبة للأشكال الهندسية مع إظهار المعادلات.

7. **إدارة المشاريع والتصدير والنسخ الاحتياطي:**
   - تخزين محلي دائم وآمن على ذاكرة المتصفح/الجهاز (IndexedDB / LocalStorage).
   - **توليد تقرير هندسي رسمي PDF** محلياً بالكامل.
   - **تصدير جدول القياسات والـ BOQ إلى Excel / CSV** مع دعم كامل للغة العربية.
   - تصدير واستعادة نسخة احتياطية كاملة بصيغة JSON.

8. **مركز المعايرة واختبارات الدقة (Verification Hub):**
   - تسجيل ومقارنة القياسات بالشريط المرجعي، وحساب الخطأ المطلق والنسبي.
   - إشعار التحقق الهندسي وإخلاء المسؤولية الميداني.

## 🚀 طريقة التشغيل والتركيب (How to Run)

### المتطلبات (Prerequisites):
- Node.js (الإصدار 18 أو أحدث)
- npm أو bun أو pnpm

### خطوات التشغيل:
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. بناء نسخة الإنتاج النهائية
npm run build
```

بعد تشغيل الأمر `npm run dev`، افتح المتصفح على:
`http://localhost:3000`

## 📱 التثبيت كـ تطبيق جوال مستقل (PWA)
التطبيق مجهز كـ Progressive Web App (PWA):
- **Android:** افتح الرابط في Chrome واضغط على القائمة (⋮) ثم اختر «تثبيت التطبيق» (Install app) أو «إضافة إلى الشاشة الرئيسية».
- **iOS:** افتح الرابط في Safari واضغط زر المشاركة (Share ⎋) ثم اختر «إضافة إلى الشاشة الرئيسية» (Add to Home Screen).
